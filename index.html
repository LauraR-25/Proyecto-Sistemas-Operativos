Detalles del Procedimiento

Procedimiento de Cálculo FIFO

1. Se ordenan los procesos por tiempo inicial (tᵢ) ascendente

2. Para cada proceso en orden:

(   a) Si es el primer proceso: tf = tᵢ + t

(   b) Si no: tf = tf(anterior) + t(actual)

3. Calcular T = tf - tᵢ

4. Calcular E = T - t

5. Calcular I = t / T

Procedimiento de Cálculo LIFO

1. Se ordenan los procesos por tiempo inicial (tᵢ) descendente

2. Para cada proceso en orden:

(   a) Si es el primer proceso: tf = tᵢ + t

(   b) Si no: tf = tf(anterior) + t(actual)

3. Calcular T = tf - tᵢ

4. Calcular E = T - t

5. Calcular I = t / T

Procedimiento de Cálculo Round Robin

1. Se ordenan los procesos por tiempo inicial (tᵢ)

2. Se crea una cola con los procesos listos

3. Se ejecuta cada proceso por un quantum Q

4. Si el proceso no termina, vuelve al final de la cola

5. tf = tiempo cuando termina la última ráfaga

6. Calcular T = tf - tᵢ

7. Calcular E = T - t

8. Calcular I = t / T
